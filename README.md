## 🚀 What I've Built

### ✅ Task Manager App — ASP.NET Core MVC Web Application *(Latest)*
> ASP.NET Core 8 · C# · Entity Framework Core · ASP.NET Identity · SQLite · Azure App Service

A full-stack task management application built on the Microsoft .NET stack — a deliberate move from Java/Spring Boot to demonstrate adaptability to the ASP.NET ecosystem. Implements complete CRUD task management with cookie-based authentication, protected routes via ASP.NET Identity, and responsive Bootstrap 5 UI with Razor Views.

Deployed on Microsoft Azure App Service (Linux, F1 tier) using Azure CLI. Solved real deployment issues including .NET version mismatch between local SDK and Azure build server, SQLite path differences between Windows local and Linux Azure runtime, and database auto-initialization on cold start.

**Highlights:** ASP.NET Identity auth · EF Core migrations · Environment-specific DB config · Azure CLI deployment · MVC architecture with dependency injection

### 🌐 PortfolioHub — 3D AI Portfolio Marketplace
> Next.js 14 · TypeScript · React Three Fiber · Node.js · PostgreSQL · Stripe · Prisma · Vercel

A full-featured marketplace where developers can browse and purchase premium portfolio templates. Built with a 3D animated hero (floating geometries via Three.js), Stripe payment flows with webhooks, JWT auth with role-based access, an admin CRUD panel, and a fully responsive editorial UI.

**Highlights:** 16 portfolio templates across 4 categories · Stripe checkout + webhook confirmation · Loading skeletons + toast notifications · Deployed live

### 🛒 Luxe Shop — Full Stack E-Commerce Platform
> Spring Boot 3.2 · React 19 · MySQL · JWT · Razorpay · Docker · Render · Vercel

A production-grade e-commerce platform with JWT authentication, Razorpay payment integration, and a role-based admin dashboard. Handles complete customer journey: browse, cart, checkout (COD + online payment), order tracking across 5 states, and admin inventory management.

Deployed end-to-end on Render (Dockerized backend) + Aiven (MySQL) + Vercel (React frontend).

**Highlights:** 25 REST API endpoints · HMAC-SHA256 payment verification · Redux Toolkit cart with localStorage persistence · Multi-stage Docker build · GitHub Actions CI/CD
